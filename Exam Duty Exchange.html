How the data is used

  • PDF Duty Chart (uploaded early) → Who is on duty on which date & slot (Invigilation / Flying / Control Room). Enough for duty swap requests.

  • Swap / exchange can be requested as soon as the Duty Chart is available — no need to wait for room allocation.
